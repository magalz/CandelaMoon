# Phase Plan Template

> The per-phase master plan. Bernstein creates this during the setup session.
> It lives in the phase folder alongside individual task files and is updated
> at the end of every session.

**File location**: `<plans-dir>/phase-N-<short-desc>/phase-plan.md`

---

```markdown
# Phase N — <Title> — <Status>

**Goal**: <one-line goal>
**Exit gate**: <measurable exit condition>
**Related ADRs**: <comma-separated ADR IDs>
**Dependencies on previous phase**: <what must be complete from Phase N-1>
**Estimated task count**: <N tasks>

---
```

## Session Update Rules

At the end of every session, Bernstein updates this plan:
1. The task's row in the Phase Tasks table: status transitions.
2. If new tasks were added mid-phase: append with next P-ID.
3. If dependencies changed: update the Depends On column.
4. If the phase transitions to Post-Phase or Maintenance: update the header status.
